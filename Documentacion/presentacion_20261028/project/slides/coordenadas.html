Dos niveles de modelo: cuerpo flotante y pata serial

q = [ rBᵀ ηBᵀ qJᵀ ]ᵀ ∈ ℝ¹⁸ qᵢ = [ qcᵢ qfᵢ qtᵢ ]ᵀ

ᴬTB = [ ᴬRB ᴬpB ; 0 0 0 1 ]

  • rB: posición del cuerpo; ηB: orientación (6 GDL)
  • qJ: los 12 ángulos articulares
  • Por pata i: coxa (qc), fémur (qf), tibia (qt)
  • Convención REP-103: x adelante, y izquierda, z arriba

La diapositiva dice que el robot se describe de dos formas, según lo que se quiera calcular.

Cuerpo flotante (el robot completo): se le dice flotante porque el cuerpo no está pegado a nada. Un brazo robótico de fábrica está atornillado a una mesa, pero el cuadrúpedo se mueve libre: avanza, sube, baja, se inclina y gira. Para describirlo hacen falta 6 números para el cuerpo (3 de posición y 3 de orientación) más los 12 ángulos de las articulaciones: 18 números. Sirve para la física completa: caídas, contacto con el suelo, equilibrio.

Pata serial (una sola pata): serial significa que las piezas van una detrás de otra, en cadena: la coxa sostiene al fémur y el fémur a la tibia, como tu brazo (hombro, codo, muñeca). Cada pata se estudia sola con 3 ángulos. Sirve para calcular dónde queda el pie, qué ángulos poner y cuánta fuerza hace cada motor. Es como estudiar un carro: para saber si se vuelca miras el carro completo; para saber cómo gira una rueda, basta esa rueda.

Primera ecuación, q = [rB ηB qJ] en R18: lista de 18 números que describe todo el robot. rB: 3 números, dónde está el cuerpo. ηB: 3 números, cómo está inclinado o girado. qJ: los 12 ángulos. La letra T (transpuesta) solo indica que se escriben en columna. «en R18» significa 18 números reales.

Segunda ecuación, qi = [qc qf qt]: los 3 ángulos de la pata i: coxa, fémur y tibia. Con 4 patas salen los 12.

Tercera ecuación, ATB = [R p; 0 0 0 1]: la transformación homogénea. Sirve para pasar la posición de un punto de un sistema de referencia A a otro B, por ejemplo de «visto desde la cadera» a «visto desde el centro del cuerpo». R es la rotación (cuánto está girado) y p el desplazamiento (cuánto está corrido). La fila 0 0 0 1 es un truco para hacer giro y desplazamiento en una sola multiplicación.

Texto de abajo:
- GDL = grados de libertad: de cuántas formas independientes se puede mover algo. El cuerpo libre tiene 6 (tres desplazamientos y tres giros).
- Convención REP-103: una norma de ROS que fija los ejes: x adelante, y a la izquierda, z arriba.
- FL delantera izquierda, FR delantera derecha, RL trasera izquierda, RR trasera derecha.
- si = +1 izquierdas, -1 derechas: las patas de un lado son el reflejo de las del otro; este signo voltea las cuentas para usar la misma fórmula en las cuatro.
- Eslabones rígidos (las piezas no se doblan), suelo plano (piso parejo), contacto unilateral (el suelo empuja el pie hacia arriba pero nunca lo jala).
