Modelo matemático

Cinemática directa de una pata

Con a = sᵢ·qc y Q = qf + qt :

x = − lf·sin qf − lt·sin Q

zp = − lf·cos qf − lt·cos Q

y = cos(a)·sᵢ·lc − sin(a)·zp

z = sin(a)·sᵢ·lc + cos(a)·zp

Ejemplo verificado

Postura nominal [qc, qf, qt] = [0,10; 0,42; −0,84] rad, con [lc, lf, lt] = [0,090; 0,105; 0,132] m:

pFL = [0,0110; 0,1112; −0,2063] m
