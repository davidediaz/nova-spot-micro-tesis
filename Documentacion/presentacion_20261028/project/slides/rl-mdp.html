El problema como proceso de decisión de Markov

MDP = ( 𝒮, 𝒜, P, r, γ )

aₜ ~ πθ( a | sₜ ) , sₜ₊₁ ~ P( · | sₜ, aₜ )

J(θ) = 𝔼τ [ Σₜ γᵗ rₜ ]

V(s) = 𝔼π [ Σₖ γᵏ rₜ₊ₖ | sₜ = s ]

Q(s, a): igual, fijando la primera acción

A(s, a) = Q(s, a) − V(s)

  • Estado s: lo que mide el robot; acción a: la corrección; recompensa r: la nota de cada paso
  • γ = 0,99: horizonte ≈ 1/(1 − γ) = 100 pasos ≈ 3 s, algo más que un ciclo de gateo
  • Ventaja A > 0: la acción fue mejor que el promedio de la política en ese estado

Nova Spot Micro · Fundamentos · Sutton y Barto (2018)

El agente observa el estado, elige una acción con su política estocástica de parámetros theta, y el entorno responde con el estado siguiente y una recompensa. El objetivo es maximizar el retorno descontado esperado. La ventaja es la diferencia entre el valor de una acción concreta y el valor medio del estado.
