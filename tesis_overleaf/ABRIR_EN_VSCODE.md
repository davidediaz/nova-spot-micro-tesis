# Trabajo local de la tesis

Archivo principal: `Thesis.tex`.

Para abrir el proyecto desde una terminal:

```bash
cd /home/pavilion/Documentos/Cuadrupedo/tesis_overleaf
code .
```

LaTeX Workshop compila al guardar y coloca los archivos generados en `build/`.
El proyecto usa pdfLaTeX, Biber y bibliografía IEEE desde
`ProyectoGradoBib.bib`.

Para abrir la vista del PDF en VS Code: `Ctrl+Alt+V`.

No edite `Thesis.pdf`: es una salida histórica incluida en el ZIP de Overleaf.
El contenido editable está en `Thesis.tex`, `Chapters/`, `Figures/` y los
archivos `.bib`.
