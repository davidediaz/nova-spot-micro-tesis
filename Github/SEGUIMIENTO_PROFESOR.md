# Seguimiento profesor–estudiante

Este archivo es el registro corto de las reuniones de seguimiento. Su función
es conectar cada comentario del profesor con una acción, una evidencia y una
decisión trazable en el repositorio.

## Ficha para cada reunión

```markdown
## Reunión AAAA-MM-DD

Participantes: estudiante, profesor/director

### Pregunta o decisión revisada

### Comentarios recibidos

### Acción acordada

### Evidencia esperada

### Fecha objetivo

### Estado
Pendiente / En curso / Bloqueada / Completada
```
